# Skills icon sources

The 15 brand SVGs in this directory are unmodified `original` icons from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), downloaded from the official repository. They are served locally with no runtime CDN requests and no icon-font package.

For each filename `<name>.svg`, the source is:
`https://raw.githubusercontent.com/devicons/devicon/v2.17.0/icons/<name>/<name>-original.svg`

Names: python, javascript, typescript, react, html5, css3, tailwindcss, nodejs, fastapi, flask, firebase, googlecloud, git, github, docker.

The [Devicon MIT license](./DEVICON-LICENSE.txt) is included. Logos identify their respective technologies; trademarks remain with their owners.

SQL is represented by the Database SVG component from the project's existing [Lucide React](https://github.com/lucide-icons/lucide) dependency. It is rendered locally and does not suggest an unprovided SQL vendor or platform.

Black Flask and GitHub marks are inverted with CSS in dark mode for contrast; their original asset files are unchanged.
